PlantMe 隐私政策

生效日期：2026年9月18日

一、我们收集什么

PlantMe 是一款本地优先的植物养护记录工具。你的所有数据——植物档案、
养护记录、照片、提醒、AI 对话历史——都存储在你自己的设备上，不会上
传到我们的服务器。

二、数据如何使用

所有数据仅用于 App 内的功能展示：植物列表、生长节律、提醒、统计等。
我们不会分析、不会共享、不会出售你的数据。

三、第三方服务

App 中部分功能会调用第三方 API，涉及数据传输：

1. 天气服务（和风天气）
   传输内容：城市名称或城市 ID
   用途：获取当前天气、未来预报、历史天气
   不涉及：你的植物数据、照片、个人信息

2. 植物识别（百度 AI）
   传输内容：你选择用于识别的照片
   用途：识别植物名称与科属
   不涉及：其他数据
   注意：只有在主动点击"识别"时才会传输

3. AI 对话（第三方大模型）
   传输内容：你的提问内容、当前讨论的植物上下文（名称、位置、最近记录等）
   用途：生成养护建议
   不涉及：照片、其他植物数据

以上服务的隐私政策由各自提供商负责：
- 和风天气：https://www.qweather.com/
- 百度 AI：https://ai.baidu.com/
- AI 服务：取决于你在设置中配置的服务商

四、数据备份

App 提供本地备份功能。备份文件由你主动导出，通过系统分享功能保存或
发送，我们不接触备份文件。

五、你的权利

- 删除任意植物：在植物详情页点击删除，会同时删除其所有记录和照片
- 清除全部数据：卸载 App 即可（iOS 卸载会清除应用数据）
- 导出数据：通过"数据备份与恢复"功能导出

六、儿童隐私

本 App 不面向 13 岁以下儿童，不会故意收集儿童个人信息。

七、权限说明

- 相机：用于拍摄植物照片
- 相册：用于选择已有照片作为记录
- 通知：用于养护提醒
所有权限都可拒绝，不影响其他功能使用。

八、政策更新

如隐私政策有重大变更，会在新版本发布时更新本文档，并在 App 内提示。
